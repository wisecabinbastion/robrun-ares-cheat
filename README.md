## ⚙️ **Detailed Features**

### **🎯 Aimbot**
- **Weapon categories**: General, pistols, rifles, shotguns, etc.
- **Hotkeys**: Activation, force aim, target switch.
- **Parameters**:
  - FOV circle (20–600 px)
  - Aim smoothness (1–20)
  - Max distance (25–600 m)
  - Humanization system (adjustable)
  - Movement prediction
  - Target filtering (police, robbers, civilians, NPCs)
  - Bone selection (head, neck, chest, etc.)
  - Ignore dead/knocked/vehicle targets

### **👁️ Player ESP**
- **Display**: 2D/3D boxes, skeletons, nicknames, clans, weapons, health, distance
- **Filtering**: By role (police, robbers, civilians), state (alive/dead), vehicles
- **Box customization**: Fill, color, thickness, distance fade
- **Extras**: Enemy lines, hide teammates/knocked players

### **🚗 Vehicle ESP**
- **Display**: Name, owner, speed, status (occupied/empty)
- **Box**: 2D/3D with color and fill options
- **Filtering**: Hide own vehicle/vehicle you're in

### **📷 Camera ESP**
- **Display**: View zones, distance, color indicators (normal/broken/alarm)
- **Filtering**: Hide broken cameras

### **💰 Loot ESP**
- **Categories**: Weapons, ammo, armor, equipment, money, crates, bags
- **Rarity filtering**: All, uncommon+, rare+, epic+, legendary
- **Extras**: Loot lines, crate contents preview

### **📡 Radar**
- **Display**: Players, vehicles, customizable position and scale
- **Parameters**: Distance (25–600 m), transparency, off-screen arrows

### **🏦 Heist ESP**
- **Objects**: Security panels, metal detectors, safes, alarms
- **NPCs**: Alert state, police call progress

### **🔫 Weapon**
- **No recoil** – Complete recoil removal
- **No spread** – Complete spread removal

### **🎮 Camera**
- **Freecam** (hotkey F9) – WASD + Space/Ctrl/Shift movement
- **Custom FOV** – 40°–140°
- **Zoom** (hotkey Z) – 5°–55° FOV

### **⚙️ Settings**
- **Configs**: Save, load, rename, delete profiles
- **UI**: Scaling (60–120%), themes (Focus blue, Ice blue, Violet, Mint, Rose, Amber, Custom)
- **Languages**: English, Russian, Chinese
- **Hotkeys**: Menu (Insert), unload, loot switch (F8)
